# 같은 표, 다른 의석: 선거제도 시뮬레이터

중학교 3학년·고등학교 사회 수업용 교사 전자칠판 시뮬레이터

---

## 프로젝트 소개

"유권자의 표는 그대로인데, 왜 선거제도가 바뀌면 의석 수가 달라질까?"

이 시뮬레이터는 **같은 득표율**을 4가지 선거제도에 적용했을 때 의석 배분이 어떻게 달라지는지를 직관적으로 보여주는 수업 보조 도구입니다. 복잡한 정치학 이론이 아니라, 학생들이 눈으로 결과 차이를 확인하는 데 초점을 맞췄습니다.

---

## 수업 목표

학생들이 이 시뮬레이터를 통해 이해해야 할 핵심 내용:

- 소선거구제는 1등 정당에게 유리할 수 있다.
- 단순다수대표제는 과반 득표 없이도 당선될 수 있다.
- 절대다수대표제는 결선투표가 필요할 수 있다.
- 중대선거구제는 소수 정당도 의석을 얻을 가능성이 커진다.
- 비례대표제는 득표율과 의석률의 차이를 최소화한다.
- 선거제도는 대표성·안정성·사표 발생·정당 체계에 영향을 준다.

## 선거제도별 계산 방식

### 1. 소선거구제 + 단순다수대표제 (FPTP)

```
함수: calculateFPTP()
```

- 12개 소선거구 각각에서 득표율이 가장 높은 정당이 1석 획득
- 과반 여부 무관 — 1위면 무조건 당선
- **동률 처리:** 정당 배열 인덱스가 낮은 정당(A당 우선) 당선
- 사표율 = (각 선거구 낙선자 득표 합계) / (전체 선거구 총득표) × 100

### 2. 소선거구제 + 절대다수대표제 (Majority Runoff)

```
함수: calculateMajorityRunoff()
```

1. 각 선거구에서 1위 득표율이 50%를 초과하면 바로 당선
2. 50% 이하이면 1위·2위 정당만 결선투표 진출
3. 결선에서 탈락한 정당의 표는 **이념 좌표** 기준으로 이동:
   - 탈락 정당 이념 ↔ 결선 후보 1 이념 간 거리
   - 탈락 정당 이념 ↔ 결선 후보 2 이념 간 거리
   - 더 가까운 결선 후보에게 전량 이동 (동거리면 반반)
4. 결선 결과에서 더 많은 표를 얻은 후보 당선

**동률 처리:** 결선 득표 동률 시 인덱스 낮은 정당 당선

### 3. 중대선거구제 (Multi-Member District)

```
함수: calculateMultiMemberDistrict()
```

- 12개 소선거구 → 4개 중선거구 (소선거구 3개씩 묶음)
- 각 중선거구의 정당 득표율 = 해당 소선거구 3개의 평균
- 각 중선거구에서 **동트 방식**으로 3석 배분 → 전체 12석

#### 동트(D'Hondt) 방식 설명

각 정당 득표율을 1, 2, 3… 으로 나눈 몫의 순위를 매겨 높은 순서대로 의석을 배분합니다.

예시 (3석 배분, A:40%, B:30%, C:20%, D:10%):

| 나눔수 | A당 | B당 | C당 | D당 |
|--------|-----|-----|-----|-----|
| ÷1 | **40** | **30** | **20** | 10 |
| ÷2 | 20 | 15 | 10 | 5 |
| ÷3 | 13.3 | 10 | 6.7 | 3.3 |

1위=40(A), 2위=30(B), 3위=20(C) → A:1석, B:1석, C:1석

**동률 처리:** 몫이 같으면 인덱스 낮은 정당(A당 우선) 의석 획득

### 4. 비례대표제 (Proportional Representation)

```
함수: calculatePR()
```

전국 정당 득표율을 기준으로 전체 의석 배분. 배분 방식은 최대잔여 또는 동트 중 선택 가능.

#### 최대잔여(Largest Remainder) 방식

```
함수: calculateLargestRemainder()
```

1. 이상적 의석 = 전체 의석 수 × (정당 득표율 / 전체 득표율)
2. 소수점 내림(floor)한 정수 부분을 먼저 배분
3. 남은 의석은 소수점 이하 잔여가 큰 정당 순서대로 1석씩 배분
4. **동률 처리:** 잔여 동률 시 인덱스 낮은 정당 우선

예시 (12석, A:40%, B:30%, C:20%, D:10%):
- A: 12×0.4=4.80 → 4석 + 잔여 0.80
- B: 12×0.3=3.60 → 3석 + 잔여 0.60
- C: 12×0.2=2.40 → 2석 + 잔여 0.40
- D: 12×0.1=1.20 → 1석 + 잔여 0.20
- 배분 완료: 4+3+2+1=10석, 남은 2석을 잔여 큰 순(A→B)에게 배분
- 최종: A=5, B=4, C=2, D=1

#### 봉쇄조항(Threshold)

- 설정값(3% 또는 5%) 미만 득표 정당은 의석 배분에서 제외
- 제외된 정당의 표는 **사표(死票)**로 표시
- 나머지 자격 정당 간에만 의석 배분

---

## 비례성 지표 — Gallagher 지수 (LSq)

```
LSq = √( 0.5 × Σ(득표율ᵢ − 의석률ᵢ)² )
```

- 0에 가까울수록 완전 비례 (득표율 = 의석률)
- 5 이하: 비례성 높음 (초록)
- 5~10: 중간 (주황)
- 10 초과: 비례성 낮음 (빨강)

## 수업 운영 팁

1. **빠른 시작**: 페이지를 열면 기본값으로 자동 시뮬레이션이 실행됩니다. 교사가 별도 입력 없이 바로 설명을 시작할 수 있습니다.

2. **탭 순서대로 설명**: 단순다수 → 절대다수 → 중대선거구 → 비례대표 순서로 설명한 뒤, 마지막에 "전체 비교" 탭에서 차이를 종합하면 효과적입니다.

3. **시나리오 활용**: 기본 시나리오(A당 40%)로 먼저 설명한 뒤, 시나리오 D(극단 분산형)로 바꿔서 "이렇게 되면 어떤 제도가 유리할까?"를 물어보세요.

4. **설명 숨기기**: 학생들에게 결과만 보여주고 "이 차이가 왜 생겼을까?"를 먼저 물어본 뒤 설명을 펼치면 더 효과적인 발문이 됩니다.

5. **정당 수 조정**: 정당 수를 2개로 줄이면 양당제 효과를, 6개로 늘리면 다당제 상황을 보여줄 수 있습니다.
