      선거구별 결과
      📖 시뮬레이터 사용법
      1
      시나리오 선택

      왼쪽 패널에서 시나리오(A~D)를 선택하면 정당별 득표율이 자동으로 설정됩니다.
      직접 득표율을 조정하고 싶으면 정당 설정 입력창에서 수정하세요.

      2
      시뮬레이션 실행

      ▶ 시뮬레이션 실행 버튼을 누르면 모든 제도의 결과가 한 번에 계산됩니다.
      실행 전 🔒 결과 가리기를 누르면 학생들이 먼저 예측할 수 있습니다.

      3
      선거제도 탐색

      상단 탭에서 선거구제와 대표 결정 방식을 바꿔가며 결과를 비교하세요.
      📊 전체 비교를 누르면 모든 제도를 한 화면에서 비교할 수 있습니다.

      4
      발문 활용

      오른쪽 패널 하단 "지금 물어볼 수 있는 질문"이 현재 탭에 맞게 자동으로 바뀝니다.
      탭을 바꿀 때마다 발문도 달라지니 바로 활용하세요.

      5
      수업 화면 정리

      ◀ ▶ 버튼으로 사이드바를 접으면 중앙 결과 화면이 넓어집니다.
      ▲ 버튼으로 개념 패널을 접고, ⛶ 버튼으로 전체화면을 활용하세요.

      💡 권장 수업 흐름 (약 20분): 시나리오 A 선택 → 소선거구+단순다수 결과 확인 → 전체 비교 탭으로 이동 → 발문 토론
